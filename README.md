# Студент.Навигатор — полезное для студентов

Статический сайт: советы по учёбе и сессии, калькулятор среднего балла, помодоро-таймер, шаблоны и полезные ссылки.
Учебный проект по дисциплине «Веб-аналитика» (Московский Политех), автор — Гирсов Валерий Александрович.

Сайт: https://xomyaxx.github.io/student-navigator/

* HTML/CSS/JS лежат в корне репозитория, без сборки.
* Бинарные файлы для скачивания (PDF, DOCX, ZIP) и og-image генерирует при деплое `_build/make_files.py` (GitHub Actions, `.github/workflows/pages.yml`).
* Места для счётчиков отмечены комментариями `<!-- COUNTER: ... -->`. Установлена Яндекс Метрика (ID 113247787, Вебвизор) на всех страницах, включая 404; установлен LiveInternet (информер 88×31 в подвале всех страниц, включая 404); Рамблер/Топ-100 и Mail.ru — пустые слоты. Номера счётчиков вписываются в `assets/js/counters-config.js`.
